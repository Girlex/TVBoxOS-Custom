检测方法与注意点

  • 这些配置普遍带 // 注释、UTF-8 BOM、尾逗号或尾部 HTML 附加内容；TVBox 使用 Gson 宽松解析 + trimJsonObject() 截取，能正常处理，本次检测按相同规则清洗。
  • 单仓配置的 spider 若为相对路径，按 fixContentPath() 规则相对配置地址补全后再验证下载。
  • 多仓配置（urls 数组）在 parseApiCollection() 中会切换成子线路地址重新加载，因此还需抽查子线路。
  • 本次仅验证「能否获取并解析配置 + 关键资源可达」，不代表所有资源站点的实际播放效果；内容合规性与稳定性请自行判断。
  • 本机直连 GitHub 与部分境外域名会超时/TLS 重置，故同时做了直连与代理两条路径的对照。
