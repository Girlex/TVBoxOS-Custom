同域名根路径、随机文件名、去掉参数、明文直连均返回同样的 302， 说明问题出在域名/空间绑定层面，而不是 wex.json 这个文件、查询参数或客户端 UA。

在 TVBox 客户端里会发生什么

  • 客户端 loadConfig() 发起 GET，OkHttp 默认跟随重定向，最终拿到 kstore.cc 的首页 HTML（1802 字节）。
  • 成功回调里调用 parseJson() → gson.fromJson(jsonStr, JsonObject.class)，HTML 无法作为 JSON 对象解析，抛出异常。
  • 界面提示「配置解析失败」；若客户端不跟随跳转，则提示「拉取配置失败」。两种情况都不会加载出任何站点。

建议

  • 该域名解析到 custom.kstore.dev，属于 KStore 自定义直链域名；整域 302 到官网通常表示域名未绑定、绑定过期或直链服务已停用，请联系接口提供方重新生成配置地址。
  • 若空间是你自己的：登录 kstore.cc 检查 wex.json 是否存在、直链是否开启、自定义域名绑定是否有效。
  • 在盒子上先换一个已知可用的配置地址验证 App 本身是否正常，再把新地址填入「配置地址」。
  • 本机直连 d.kstore.dev:443 会出现 TLS 连接被重置，测试时需走代理；盒子端若在国内网络也可能受此影响。
